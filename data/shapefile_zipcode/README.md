# Shapefiles

This folder contains geographic boundary shapefiles used for spatial analyses 
and mapping within the study area.  

Shapefiles are not included in this repository because of file size limitations. 
The data can be obtained from the 
[US Census Bureau’s MAF/TIGER System](https://www.census.gov/cgi-bin/geo/shapefiles/index.php?year=2020&layergroup=ZIP%20Code%20Tabulation%20Areas).
